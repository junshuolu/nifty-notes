# Changelog

## 2026-03-17

这个版本把原来的 `Composer Prototype` 扩展成了一个可实际使用的 `Nifty Notes` 双谱表钢琴编辑器。

### 本版本完成的内容

- 品牌统一改为 `Nifty Notes`
- 去掉左上角旧的 `///` 标记
- 更新页面标题、顶部文案和产品名称
- 增加拍号切换：`4/4`、`3/4`、`2/4`
- 拍号切换后，渲染、吸附、播放时值都会跟随变化
- 支持双谱表 26 个自然音输入，范围为 `C2` 到 `G5`
- 音符数据结构升级为支持和弦
- 同一拍位重复点击可以给和弦加音或减音
- 支持和弦播放
- 支持相同单音或相同和弦之间的 tie
- 增加更稳定的和弦符干方向处理
- 保留原有 `Dot` 交互方式：先选时值，再点 `Dot`
- 八分音符在支持的拍号下按拍自动连梁
- 空白谱面默认显示可编辑的 rest 骨架
- 插入音符后，未操作位置的默认 rest 会继续保持，不会整体跳样式
- 修复 bar 内默认 rest 会被音符挤偏、上下乱跑的问题
- 新增面向初学者的 `README`
- 新增版本说明 `CHANGELOG`
- 新增本地参考文档 `project-handbook.local.md`，并通过 `.gitignore` 排除，不参与提交

### 当前保留的限制

- 切换拍号时会保留 bar 数量，但会清空当前谱面内容
- 当前只支持自然音，不支持升降记号
- 当前仍是纯前端项目，不依赖后端
