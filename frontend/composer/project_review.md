# Project Review

## 当前项目状态

`Nifty Notes` 目前是一个已经可部署、可演示、可基础试用的双谱表钢琴作曲器前端原型。

当前已经具备：

- 双谱表点选录入
- 和弦输入
- 拍号切换
- 附点
- 默认空白谱面保持四分休止符骨架，只有实际写入的那一拍会继续细分
- 回放
- 静态部署


## 这一轮解决的问题

### 1. 休止符视觉位置

问题：

- 休止符在每个 bar 里看起来偏右，读谱不自然

处理：

- 对休止符做了单独的横向偏移，让它在固定网格上略微向左

### 2. 点击后声音延迟

问题：

- 第一次点击音符时，钢琴采样加载导致预览音明显延迟

处理：

- 点击插入时先给一个即时预览音
- 同时在后台继续加载钢琴采样
- 之后正式播放仍然使用钢琴音色

### 3. 点到的音和落下的音不一致

问题：

- 客户反馈：点 `B4` 容易落成 `A4`
- 鼠标悬停和实际插入不够直观

处理：

- 修正高音谱表和低音谱表的顶部基准线映射
- 现在谱面点击、预览标签、实际落点三者保持一致

### 4. Tempo / Metronome

问题：

- 原先右上角只有固定的 `Tempo 80 BPM`
- 不能改速度，也不能开关节拍器

处理：

- 把右上角 Tempo 改成可点击的设置面板
- 支持直接调 BPM
- 支持 Metronome On / Off

### 5. 播放轨迹不明显

问题：

- 播放时看不出当前播到了哪里

处理：

- 新增贯穿高音和低音谱表的竖向播放线
- 播放过程中可直接看到当前经过的位置

### 6. 占位休止符不应该整小节预铺满

问题：

- 切到 `Whole`、`Half`、`Eighth`、`Sixteenth` 后，不应该把整小节都预先显示成对应时值
- 实际只改前面某个 bar 时，后面已经写过十六分音符的小节会跟着重新挤乱
- 休止符整体还需要再向左一点，避免密集区域看起来贴线

处理：

- 占位休止符重新收回到默认四分骨架，切换 `Note Value` 只影响插入行为，不再整小节预铺满
- 只有真正写入内容的那一拍 / 那一段，才会把原来的四分休止符位置继续细分替换
- 每个 bar 的渲染重新互相隔离，去别的小节编辑时，不会再把已有密集音型的小节重新挤压
- 休止符再向左微调，实际音符与悬停预览继续保留 barline 边界约束

### 7. 末尾十六分音符和 Half 预览对位仍不稳定

问题：

- 十六分音符插在最后一个槽位时，末尾休止符容易贴住 barline，甚至看起来没有被替换掉
- 同一小节的高音谱表和低音谱表在密集音型下仍然可能互相干扰
- `Half` 等较长时值的蓝色悬停预览和真实插入位置不完全一致

处理：

- 把固定 bar 宽改成按每个 beat 的真实节奏密度扩宽，让最后一个十六分位置和末尾八分位置都不再被压短
- 占位休止符改成继承当前 beat 的最小时值分辨率；某个 beat 一旦写入 16 分或 8 分，剩余空位就按同级 rest 补齐
- 同一 measure 仍共享 barline，但高音谱表和低音谱表改成各自按自己的内容宽度排布，避免一个音部改动后把另一个音部的音符重新挤乱
- 把八分音符和十六分音符的点击吸附从向左取整改成就近落位，连续补小音值时更容易连起来
- 悬停预览和真实符号统一使用同一套边界估算，让 `Half` 等时值的预览和落点重新对齐

### 8. 当前 beat 的占位休止符还需要更贴手

问题：
- 八分音符虽然已经能自动拓宽，但空拍位的 placeholder 还需要更像老师手写时的渐进替换，而不是一下子把整拍拆满。
- 十六分音符在空拍位里如果一开始就把四个十六分休止符全部铺开，会显得太散，也不利于连续点击。
- 在低音部继续细分时，用户仍然会主观感受到高音部对应拍位也在一起变化。

处理：
- 给当前鼠标所在 / 刚刚点击的那个 beat 增加独立 focus，只让这一拍、这一行谱表响应当前 `Note Value` 的 placeholder 细分。
- `8th` 的空拍位先显示两个八分休止符；`16th` 的空拍位先显示 `16th + 16th + 8th`，等这一拍真的写进十六分内容后，再把后半拍八分休止符拆成两个十六分休止符。
- 八分 / 十六分拍位的自动扩宽比例重新收窄，既保留更均匀的点击槽位，也避免单拍被拉得过宽。
- 高音谱表和低音谱表的 placeholder focus 分开处理；继续在低音部补写时，不再同时重排高音部当前拍位的占位休止符。

## 这一轮顺手统一的地方

- `Duration` 改为 `Note Value`
- `Meter` 改为 `Time Signature`

## 目前仍然存在的限制

- 只支持自然音，不支持升降记号
- 暂时没有保存、导出和账号系统
- 拍号切换仍然会清空现有谱面
- 第一次完整播放如果钢琴采样尚未准备好，仍然可能先经历一次加载

## 下一轮建议

1. 加强八分音符和十六分音符的小拍位点击提示，让“连续填 quavers / semis”更轻松。
2. 增加保存草稿和导出能力，避免每次刷新都重新输入。
3. 继续补老师视角和课程视角，而不只是作曲器本身。
