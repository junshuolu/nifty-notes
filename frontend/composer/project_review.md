# Project Review

## 当前项目状态

`Nifty Notes` 目前是一个已经可部署、可演示、可基础试用的双谱表钢琴作曲器前端原型。

当前已经具备：

- 双谱表点选录入
- 和弦输入
- 拍号切换
- 附点
- 回放
- 静态部署

## 这一轮解决的问题

### 1. 休止符视觉位置

问题：

- 休止符在每个 bar 里看起来偏右，读谱不自然

处理：

- 对休止符做了单独的横向偏移，让它在固定网格上略微向左

### 2. 点击后声音延迟

问题：

- 第一次点击音符时，钢琴采样加载导致预览音明显延迟

处理：

- 点击插入时先给一个即时预览音
- 同时在后台继续加载钢琴采样
- 之后正式播放仍然使用钢琴音色

### 3. 点到的音和落下的音不一致

问题：

- 客户反馈：点 `B4` 容易落成 `A4`
- 鼠标悬停和实际插入不够直观

处理：

- 修正高音谱表和低音谱表的顶部基准线映射
- 现在谱面点击、预览标签、实际落点三者保持一致

### 4. Tempo / Metronome

问题：

- 原先右上角只有固定的 `Tempo 80 BPM`
- 不能改速度，也不能开关节拍器

处理：

- 把右上角 Tempo 改成可点击的设置面板
- 支持直接调 BPM
- 支持 Metronome On / Off

### 5. 播放轨迹不明显

问题：

- 播放时看不出当前播到了哪里

处理：

- 新增贯穿高音和低音谱表的竖向播放线
- 播放过程中可直接看到当前经过的位置

## 这一轮顺手统一的地方

- `Duration` 改为 `Note Value`
- `Meter` 改为 `Time Signature`

## 目前仍然存在的限制

- 只支持自然音，不支持升降记号
- 暂时没有保存、导出和账号系统
- 拍号切换仍然会清空现有谱面
- 第一次完整播放如果钢琴采样尚未准备好，仍然可能先经历一次加载

## 下一轮建议

1. 加强八分音符和十六分音符的小拍位点击提示，让“连续填 quavers / semis”更轻松。
2. 增加保存草稿和导出能力，避免每次刷新都重新输入。
3. 继续补老师视角和课程视角，而不只是作曲器本身。
